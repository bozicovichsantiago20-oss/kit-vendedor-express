# Bundle Vendedor Express

Pack combinado para vendedores online que quieren respuestas listas, auditoria de publicacion y material Pro en una sola descarga.

No esta afiliado a Mercado Libre, Meta, WhatsApp ni Instagram. Usalo como material de trabajo y adapta cada texto a tu negocio.

## Incluye

- `kit-vendedor-express.zip`: pack base con 130+ respuestas, prompts, checklist y plan de 7 dias.
- `kit-vendedor-express-pro.zip`: pack Pro con 200+ respuestas, objeciones, prompts avanzados, seguimiento y recompra.
- `auditoria-express-publicacion.zip`: auditoria de publicacion con checklist, diagnostico, guion de mejora y plan de 48 horas.

## Uso sugerido

1. Empieza con la auditoria para detectar que mejorar en una publicacion.
2. Usa el pack base para cargar respuestas frecuentes.
3. Usa el Pro para objeciones, seguimiento, recompra y publicaciones mas completas.

## Precio sugerido

Bundle digital: USD 15 o equivalente local.
