# Guia para cargar respuestas rapidas

## 1. Elegi las preguntas que mas se repiten

Revisa chats, preguntas de publicaciones y mensajes de WhatsApp. Anota las 10 consultas mas frecuentes.

Ejemplos:

- Tenes stock?
- Cuanto demora el envio?
- Haces factura?
- Tiene garantia?
- Me sirve para este modelo?
- Puedo cambiarlo?

## 2. Crea una respuesta base

La respuesta debe tener:

1. Saludo corto.
2. Respuesta concreta.
3. Dato verificable.
4. Siguiente paso.

Ejemplo:

Hola. Si, tenemos stock de [producto]. Podes comprar directamente desde la publicacion y el sistema te muestra el plazo de envio antes de pagar.

## 3. Guarda variantes por tono

Usa tono claro para marketplace, cercano para WhatsApp e Instagram, y firme para condiciones sensibles como cambios, garantias o reclamos.

## 4. Revisa una vez por semana

Si una pregunta aparece muchas veces, agrega ese dato a la publicacion. Una buena publicacion reduce preguntas repetidas.

## 5. Mide si funciona

Durante 7 dias anota:

- cantidad de consultas recibidas
- tiempo promedio de respuesta
- preguntas repetidas
- ventas cerradas por chat

Si baja la demora y suben las respuestas completas, el sistema esta funcionando.
