# Fuentes y decision de oportunidad

Fecha: 2026-06-04.

## Senales externas

- CACE informa que el eCommerce argentino siguio creciendo en 2025: facturacion +55%, unidades vendidas +28%, 253 millones de ordenes y mas de un millon de nuevos compradores online.
- Mercado Libre promueve respuestas rapidas y asistencia con IA para vendedores, incluyendo mejorar publicaciones y responder preguntas de compradores.
- PayPal.Me permite compartir un enlace para recibir pagos de clientes o actividad freelance sin armar checkout complejo. PayPal tambien documenta que se puede agregar monto y codigo de moneda al final del enlace, por ejemplo `/5USD`, para pedir un importe concreto.

## Decision

Crear un producto digital chico para vendedores online argentinos:

**Kit Vendedor Express**: generador gratis + pack pago sugerido de USD 5.

## Por que no repetir otros proyectos

- El proyecto `generar usd` ya trabaja servicios de automatizacion IA para PyMEs, prospectos y auditorias.
- El proyecto `animes` ya trabaja crecimiento de reels y monetizacion por contenido.
- El proyecto `juego movil` ya trabaja una demo mobile con monetizacion futura de stores/anuncios.

Este producto se diferencia porque:

- Se puede publicar como sitio estatico.
- Usa cobro directo con PayPal/CBU.
- Tiene entrega inmediata por descarga.
- Sirve a un dolor concreto: responder mejor y mas rapido para vender online.
