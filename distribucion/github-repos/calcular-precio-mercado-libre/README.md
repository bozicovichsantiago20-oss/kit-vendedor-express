# Calcular precio de venta Mercado Libre

Recurso para vendedores que quieren revisar costo, comision, envio, impuestos y margen antes de bajar precio.

Guia completa:

https://bozicovichsantiago20-oss.github.io/kit-vendedor-express/guias/calcular-precio-venta-mercado-libre.html

## Formula base

`precio minimo = costo + embalaje + cargos + comision + envio absorbido + impuestos + margen minimo`
