# Permisos necesarios para distribucion con cuentas personales

Estas acciones pueden generar alcance real, pero publican contenido desde cuentas personales o canales con comunidad. Requieren confirmacion concreta antes de enviar.

## Requieren confirmacion

- Publicar en Reddit desde una cuenta logueada.
- Publicar en Facebook o grupos.
- Enviar WhatsApp a contactos o grupos.
- Publicar en LinkedIn.
- Enviar emails a listas o contactos.
- Crear productos en marketplaces externos como Gumroad, Ko-fi, Payhip o similares.

## No ejecutar automaticamente sin confirmacion

- Spam masivo.
- Mensajes directos no solicitados en volumen.
- Comprar publicidad.
- Usar cuentas o datos sensibles.
- Prometer resultados garantizados.

## Texto recomendado para pedir confirmacion

Confirmame: "Autorizo publicar el Kit Vendedor Express en [canal] usando este texto".
