# Calculadora de descuentos para Mercado Libre

Herramienta gratis para vendedores que quieren activar una promocion o descuento sin perder margen.

## Que calcula

- Precio promocional.
- Comision o cargo variable estimado.
- Impuestos u otros porcentuales.
- Envio absorbido por el vendedor.
- Ganancia neta.
- Margen sobre costo.
- Precio minimo para margen objetivo.
- Descuento maximo recomendado.

## Cuando usarla

- Antes de activar una promocion en Mercado Libre.
- Antes de copiar el descuento de un competidor.
- Cuando el envio gratis puede comerse el margen.
- Cuando la publicacion solo vende si bajas precio.
- Antes de pedir una auditoria de publicacion.
