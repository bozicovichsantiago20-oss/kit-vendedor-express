# Distribucion prioritaria legitima

Fecha: 2026-06-06 16:48 ART.

## Criterio

Usar solo canales que permitan recursos gratuitos, herramientas no-login o productos digitales sin spam. Evitar formularios muertos, pagos obligatorios, automatizacion agresiva o cuentas personales nuevas sin confirmacion.

## Canales priorizados

1. Tool Commons
   - URL: https://toolcommons.org/
   - Motivo: directorio de herramientas open-source, no-login, no tracking y estaticas.
   - Uso recomendado: enviar herramienta gratis principal, no pagina de pago.
   - Estado: ya hay trabajo previo con ToolCommons; seguir solo si hay nueva evidencia o si piden cambios.

2. Zearches
   - URL: https://zearches.com/
   - Motivo: directorio gratuito sin login para webs, blogs, recursos y herramientas.
   - Uso recomendado: listar `empezar.html` o home si el formulario acepta URL principal.
   - Estado: no forzar clones; usar una sola URL central.

3. SaaSCity
   - URL: https://saascity.io/submit
   - Motivo: listado gratuito para productos digitales/herramientas.
   - Uso recomendado: probar solo si acepta producto estatico sin cuenta personal sensible.

4. Neeed Directory
   - URL: https://neeed.directory/
   - Motivo: lista herramientas, SaaS, recursos y productos.
   - Uso recomendado: preparar ficha, enviar solo si el formulario permite recurso gratuito/estatico.

5. SaaS Cubes
   - URL: https://saascubes.com/
   - Motivo: tiene plan gratuito, pero puede requerir backlink.
   - Uso recomendado: evaluar solo si no obliga pago ni spam.

## No priorizar

- NoSubscription.org: aparece como directorio de software one-time, pero el envio redirige a Stripe/pago.
- Directorios con formulario roto, DNS caido o bloqueo diario.
- Comunidades donde publicar seria spam o autopromocion no permitida.
