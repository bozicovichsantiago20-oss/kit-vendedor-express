Fecha: 2026-06-07 09:38 ART.

## Regla de decision

El proyecto no se evalua por cantidad de paginas, commits, micrositios o articulos. Se evalua por:

- trafico util;
- clics a compra;
- pedidos reales;
- pagos confirmados;
- evidencia verificable en PayPal, CBU, GitHub Issues o registros publicos.

Estado actual verificado: 0 USD generados, 0 USD por cobrar, 0 pedidos abiertos, 6 vistas / 1 unico en GitHub y 2936 clones / 564 unicos reportados por la API de traffic del repositorio principal. Las descargas de release no prueban pago y no se cuentan como ingresos; luego del reemplazo de ZIPs, las descargas actuales de Base, Auditoria y Bundle estan en 0.

## Activos B - trafico y educacion con potencial

- Herramientas gratis: generadores, calculadoras y priorizador. Sirven si cada una muestra caso real, CTA y comparacion con producto pago.
- Guias SEO de precio, descuento, envio gratis, promociones, respuestas, WhatsApp y reclamos. Sirven si empujan hacia Base, Auditoria o Bundle.
- Landings en ingles. Sirven para directorios gratuitos, pero no deben desplazar el foco de venta principal.
- Telegra.ph, Gists, README y perfil GitHub. Sirven como superficies publicas de descubrimiento.

## Activos C - no dedicar mas tiempo sin evidencia

- Clones o micrositios casi identicos sin trafico ni pedidos.
- Paginas de distribucion internas que no reciben visitas y no tienen schema ni CTA claro.
- Directorios bloqueados, muertos, con pago obligatorio, con formularios rotos o con requisitos de cuenta que el usuario no autorizo.
- Nuevas ofertas que no sean Base, Auditoria o Bundle.

## Trabajo descartado por bajo retorno

- No crear mas articulos duplicados sobre el mismo tema.
- No abrir mas micrositios repetidos hasta que exista Search Console, Bing Webmaster o Analytics con trafico real.
- No perseguir directorios pagos o que pidan cuentas personales nuevas.
- No crear nuevas herramientas si no venden directamente Base, Auditoria o Bundle.
