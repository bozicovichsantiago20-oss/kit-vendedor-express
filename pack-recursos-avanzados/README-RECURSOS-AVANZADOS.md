# Recursos Avanzados Vendedor Express

Version ampliada para vendedores online que quieren ordenar atencion, publicaciones, precio y seguimiento.

No esta afiliado a Mercado Libre, Meta, WhatsApp ni Instagram. Usalo como material de trabajo y adapta cada texto a tu negocio.

## Incluye

- Todo el Kit Vendedor Express base.
- `respuestas-avanzadas-por-rubro.csv`: 72 respuestas extra para situaciones de preventa, postventa y cierre.
- `matriz-objeciones-precio.csv`: respuestas para objeciones de precio, envio, descuento y comparacion.
- `prompts-avanzados-publicaciones.md`: prompts avanzados para analizar y mejorar publicaciones.
- `seguimiento-consultas.csv`: plantilla para medir consultas, respuestas, cierres y problemas.
- `auditoria-publicacion-mercado-libre.md`: checklist de auditoria para relanzar una publicacion.
- `mensajes-recompra-postventa.md`: mensajes de recompra, seguimiento y postventa.

## Como usarlo

1. Usa el kit base para cargar respuestas frecuentes.
2. Abre `respuestas-avanzadas-por-rubro.csv` y filtra por rubro o situacion.
3. Usa la matriz de objeciones cuando el comprador discute precio, envio o descuento.
4. Revisa una publicacion por semana con la auditoria.
5. Mide consultas y cierres en `seguimiento-consultas.csv`.
