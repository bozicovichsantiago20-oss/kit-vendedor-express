# Auditoria Pro de publicacion para Mercado Libre

Usa esta guia para revisar una publicacion antes de bajarle el precio.

## 1. Titulo

- Incluye producto principal.
- Incluye marca o linea si aporta confianza.
- Incluye modelo, medida, talle o compatibilidad.
- Evita relleno que no ayuda a buscar.

## 2. Primera pantalla

- La primera foto muestra el producto real o una vista clara.
- El comprador entiende que recibe.
- El precio no queda desconectado del beneficio.
- Las variantes estan ordenadas.

## 3. Descripcion

Debe responder:

- Que incluye.
- Para quien sirve.
- Medidas o compatibilidad.
- Materiales o especificaciones.
- Condiciones de garantia.
- Como se gestiona envio o retiro.
- Que hacer ante cambio, devolucion o reclamo.

## 4. Preguntas repetidas

Si tres compradores preguntan lo mismo, la publicacion necesita mejorar ese dato.

Registra:

- Pregunta repetida.
- Donde agregar la respuesta.
- Respuesta rapida que se debe guardar.
- Fecha de cambio.

## 5. Precio

Antes de bajar precio, revisa:

- Costo real.
- Comision.
- Envio absorbido.
- Impuestos.
- Embalaje.
- Margen minimo.
- Posible combo o pack.

## 6. Respuestas rapidas minimas

Guarda respuestas para:

- Stock.
- Envio.
- Medidas o compatibilidad.
- Garantia.
- Factura.
- Descuento.
- Retiro.
- Cambio/devolucion.
- Reclamo.
- Mayorista.

## 7. Decision

Al terminar la auditoria, decide una accion:

- Mejorar titulo.
- Cambiar fotos.
- Agregar medidas.
- Ajustar precio.
- Crear combo.
- Guardar respuestas.
- Pausar publicacion si el margen no sirve.
