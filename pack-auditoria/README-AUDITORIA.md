# Auditoria Express de Publicacion Marketplace

Pack practico para revisar una publicacion antes de bajar precio o relanzarla.

No esta afiliado a Mercado Libre, Meta, WhatsApp ni Instagram. Usalo como material de trabajo y adapta cada punto a tu negocio.

## Incluye

- `checklist-auditoria-publicacion.csv`: 42 puntos de revision para titulo, fotos, descripcion, precio, envio y postventa.
- `plantilla-diagnostico-publicacion.csv`: hoja para registrar problemas, impacto y accion concreta.
- `guion-mejora-publicacion.md`: estructura para reescribir una publicacion con mas claridad.
- `respuestas-para-publicacion.md`: respuestas que conviene guardar segun las dudas repetidas.
- `plan-48hs-relanzamiento.md`: rutina de dos dias para corregir, publicar y medir.

## Como usarlo

1. Abri el checklist y marca cada punto como OK, mejorar o no aplica.
2. Pasa los problemas importantes a la plantilla de diagnostico.
3. Reescribe titulo, descripcion y preguntas frecuentes con el guion.
4. Guarda respuestas rapidas para dudas repetidas.
5. Relanza y mide durante 48 horas.
